# LeetCode SQL 50

A collection of my solutions to the **LeetCode SQL 50** study plan.

This repository is created for practicing SQL concepts and preparing for technical interviews. The problems cover essential SQL topics such as:

* SELECT and filtering
* Sorting and grouping
* Aggregate functions
* JOINs
* Subqueries
* String and date manipulation
* Conditional expressions
* Window functions

Each problem contains the SQL solution along with the corresponding LeetCode problem number and title.

**Goal:** Complete all 50 problems and build a strong foundation in SQL for coding interviews.
